# Manabase（Padlet風 振り返りボードアプリ）

授業の振り返りを **Padlet のように** カードで貼り付けていく Web アプリです。
**外部APIは一切使いません**（Google Apps Script の組み込み機能 `SpreadsheetApp` / `DriveApp` のみ）。
APIキー・Google Cloud の有効化・課金は不要で、**サーバーも不要**です。

データは **スプレッドシート**、写真・動画は **Google ドライブ** に自動で蓄積されます。

> **1デプロイ＝1クラス** の想定です。クラスごとにこのプロジェクトをコピーしてデプロイしてください（クラスコードはありません）。

## 主な機能

### 生徒
- ログイン画面で **自分の名前を選択 → パスワードを入力**してログイン
  - **初回ログイン時に自分でパスワードを設定**（次回からそのパスワード）
- ボード内の **セクション（列）** に振り返りを投稿（テキスト＋写真／動画、カード色も選択可）
- **写真は自動で軽量化**してアップロード。**動画**もそのまま添付可
- **カメラ起動**：その場で **写真撮影・動画録画**して投稿（PCはライブカメラ、スマホは標準カメラ）
- **自分の投稿は編集**できる（カードの「✏ 編集」）
- カードの **ドラッグ＆ドロップ**（セクション間移動・並べ替え）
- **いいね ❤** と **コメント 💬**
- 投稿は **自動でリアルタイム反映**（更新ボタン不要。約7秒ごとに同期）

### 先生（先生用ログイン）
- 初回ログイン時に先生用パスワードを設定
- **名簿管理**：1人ずつ追加／**Excel等からの一括貼り付け**／パスワードのリセット・削除
- **ボード作成**：**教科 × 単元名**（＋日付・任意タイトル）。教科ごとに色分け表示
- ボードを見ながら **セクションの追加・改名・削除**
- **どの投稿も編集・削除**できる
- **確認・出力**：ボード全体／児童別を印刷・PDF出力

## データの保存先

| データ | 保存先 |
| --- | --- |
| 名簿・ボード・セクション・振り返り本文・いいね・コメント | スプレッドシート「Manabase データ」 |
| 写真・動画 | ドライブ「Manabase 写真」（`教科_単元名` ごとのサブフォルダ） |

スプレッドシートの各シートとドライブフォルダは **初回アクセス時に自動作成** されます（手動の初期化は不要）。

## セットアップ

### 方法A：clasp（推奨）

```bash
npm install -g @google/clasp
clasp login
clasp create --type standalone --title "Manabase" --rootDir ./src
clasp push
```

### 方法B：手動コピー

1. <https://script.google.com> で新規プロジェクトを作成
2. `src/Code.gs` の内容を `コード.gs` に貼り付け
3. ファイル＋から **HTML** ファイル `Index` を作成し、`src/Index.html` の内容を貼り付け
4. 「プロジェクトの設定」→「`appsscript.json` マニフェスト ファイルをエディタで表示する」をオンにし、`src/appsscript.json` の内容で上書き

### デプロイ

1. 右上 **「デプロイ」→「新しいデプロイ」→「ウェブアプリ」**
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
2. 初回は権限の承認が必要です（承認後、シートとフォルダが自動作成されます）
3. 発行された URL を生徒に共有

> クラスを増やすときは、このプロジェクトを丸ごとコピーして別途デプロイしてください。

## 使い方の流れ

1. 先生が「先生用ログイン」でパスワードを設定（初回）
2. 「名簿管理」で生徒を登録（Excelからコピー → 一括貼り付けが便利）
3. 「ボード作成」で教科・単元名を指定してボードを作成
4. 生徒に URL を共有
5. 生徒：名前を選ぶ → 初回はパスワード設定 → ボードを開いて投稿
6. 先生：「確認・出力」からボード全体／児童別を印刷・PDF出力

## ファイル構成

```
src/
├── appsscript.json   … マニフェスト（権限・タイムゾーン・Webアプリ設定）
├── Code.gs           … サーバー（初期化・認証・名簿・ボード・振り返り・出力）
└── Index.html        … クライアント（UI・ログイン・ボード・先生画面すべて）
```

## カスタマイズ

- 教科の選択肢：`Index.html` の `SUBJECTS`
- カードの色：`Index.html` の `COLORS`
- 写真の最大サイズ・画質：`Index.html` の `compress(file, 1280, 0.82)` の引数

## セキュリティについて

- パスワードは SHA-256 ＋ ソルトでハッシュ化して保存します（平文では保存しません）。
- 写真は表示のため「リンクを知っている全員が閲覧可」に設定されます。校内ポリシーに応じて調整してください。
- 校内利用を想定した簡易認証です。厳密なアクセス制御が必要な場合は Google アカウント認証への切り替えを検討してください。
