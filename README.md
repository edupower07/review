# 振り返りボード（Padlet風アプリ）

授業の振り返りを **Padlet のように** カードで貼り付けていける Web アプリです。
Google Apps Script で動くため **サーバー不要**。データは **スプレッドシート**、写真は **Google ドライブ** に自動で蓄積されていきます。

## できること

- 🧑‍🎓 **生徒**：クラスコードを入力 → ボードを開く → 名前を選んで振り返りを投稿（テキスト＋写真）
- 🧑‍🏫 **先生**：パスコードでログインして
  - クラスの作成・**名簿管理**（1人ずつ／一括登録）
  - **ボード作成**（教科 × 日付 で作成）
  - 投稿された**振り返りの閲覧・削除**
- 📊 振り返りは **スプレッドシート** に1行ずつ記録されて溜まっていく
- 🖼 写真は **ドライブ**（教科_日付ごとのサブフォルダ）に保存

## データの保存先

| データ | 保存先 |
| --- | --- |
| クラス・名簿・ボード・振り返り本文 | スプレッドシート「振り返りボード データ」 |
| 写真 | ドライブ「振り返りボード 写真」フォルダ |

スプレッドシートとフォルダは初回 `setup()` 実行時に自動作成され、ID は Script Properties に保存されます。

## セットアップ手順

### 方法A：clasp を使う（推奨）

[clasp](https://github.com/google/clasp) を使うとローカルのコードをそのままアップロードできます。

```bash
npm install -g @google/clasp
clasp login

# 新しいスタンドアロンの Apps Script プロジェクトを作成
clasp create --type standalone --title "振り返りボード" --rootDir ./src

# 生成された .clasp.json を確認（scriptId が入っていればOK）
clasp push
```

> `.clasp.json.example` を参考に、既存プロジェクトに紐づける場合は `scriptId` を書き換えてください。

### 方法B：手動コピー

1. <https://script.google.com> で新規プロジェクトを作成
2. `src/` 内の各ファイルを以下の対応でコピー
   - `*.gs` → スクリプトファイル（`Code.gs`, `Api.gs`）
   - `*.html` → HTML ファイル（`index.html`, `styles.html`, `javascript.html`）
   - `appsscript.json` → 「プロジェクトの設定」で「マニフェストを表示」をオンにして上書き

### 共通：初期化とデプロイ

1. エディタで関数 **`setup`** を一度だけ実行（初回は権限の承認が必要）
   - スプレッドシートとドライブフォルダが作成されます
   - 先生用パスコードの初期値は **`1234`**
2. パスコードを変更する場合は `setTeacherPasscode("好きな数字")` を実行
3. 右上 **「デプロイ」→「新しいデプロイ」→「ウェブアプリ」**
   - 「次のユーザーとして実行」：**自分**
   - 「アクセスできるユーザー」：**全員**
4. 発行された URL を生徒に共有

## 使い方の流れ

1. 先生が「先生用」からログイン → クラスを作成（クラスコードが発行される）
2. 名簿を登録（一括登録は「1,山田太郎」のように1行1名）
3. 「ボード作成」で教科と日付を選んでボードを作る
4. 生徒に **URL とクラスコード** を伝える
5. 生徒：コード入力 → ボード選択 → ＋ボタンで振り返り投稿

## ファイル構成

```
src/
├── appsscript.json   … マニフェスト（権限・タイムゾーン・Webアプリ設定）
├── Code.gs           … セットアップ・ルーティング・共通ヘルパー
├── Api.gs            … クライアントから呼ぶサーバーAPI（クラス/名簿/ボード/振り返り）
├── index.html        … 画面のHTML骨格
├── styles.html       … スタイル（Padlet風UI）
└── javascript.html   … クライアントロジック（生徒画面＋先生画面）
```

## 補足・カスタマイズ

- 教科の選択肢は `javascript.html` の `SUBJECTS` 配列で変更できます。
- カードの色は `COLORS` 配列で変更できます。
- 写真は「リンクを知っている全員が閲覧可」に設定されます（画像表示のため）。校内ポリシーに応じて調整してください。
